# 最小可玩纵向切片：岚州市产业整改

> 本文中的地区、人物、企业、数字和事件均为虚构，仅用于游戏原型设计。

## 1. 目的

这个纵向切片不是完整仕途游戏，而是一局 30—45 分钟、六个回合的短局，用于验证最核心的产品假设：

1. 玩家像领导者一样定方向和授权，而不是亲自编写实施方案；
2. 不同 NPC 会基于局部信息和自身责任塑造方案；
3. 自由文本和预设选项遵循同一套权限、资源和后果规则；
4. 承诺、执行偏差和责任痕迹能够跨回合产生后果；
5. 玩家能够理解结果来自哪里，而不是被 LLM 随意裁定。
6. 玩家能通过有成本的人物会谈获取信息、试探条件并形成可追踪的私下交办。

## 2. 玩家身份

玩家姓名和少量履历由开局选择，固定背景如下：

- 43 岁；
- 新任中部虚构地级市“岚州市”市委书记，到任三周；
- 此前在省级部门和另一个地级市工作，熟悉政策但缺乏本地关系；
- 上级要求尽快处理已经拖延两年的北岭焦化产业整改；
- 前任已调离，但遗留会议纪要和若干没有完全公开的承诺。

这一身份让玩家拥有较强议程权，却缺少本地信息网络，能够突出授权和信息不对称。

## 3. 城市背景

岚州市人口约 380 万，以能源、化工、装备制造和农业为主。北山县焦化产业集群是传统工业核心：

- 占全市规模以上工业增加值约 19%；
- 贡献地方相关税收约 14%；
- 直接就业约 13,000 人，带动运输、洗煤和维修等上下游就业；
- 三家主要企业中，两家现金流紧张；
- 部分生产线未达到新的整改要求；
- 市县两级政府债务空间有限，不能轻易提供兜底融资。

省级整改复核将在十二周后进行。未完成阶段性目标可能导致项目审批受限和相关责任追究；一次性关停则会冲击就业、县级财政和银行资产质量。

## 4. 初始公开状态

玩家界面显示趋势，不显示所有隐藏数值。

| 领域 | 初始状态 | 玩家看到的说明 |
|---|---:|---|
| 财政韧性 | 偏弱 | 市县两级可新增支出空间有限 |
| 就业稳定 | 尚可 | 北山县高度依赖焦化及上下游 |
| 环境合规 | 较差 | 省级复核期限临近 |
| 社会矛盾 | 中等 | 暂无大规模公开事件 |
| 上级组织信用 | 中等 | 新书记处于观察期 |
| 班子协调 | 未知 | 多数成员仍在判断新书记风格 |
| 行政执行能力 | 中等 | 对专项任务依赖领导督办 |
| 历史责任暴露 | 未知 | 前任时期资料尚未完全梳理 |

## 5. 核心人物

### 5.1 周立衡，市长

- **权限**：主持市政府全面工作，掌握财政和行政执行链。
- **公开立场**：支持整改，但反对没有资金来源的政治表态。
- **真实关切**：避免政府形成新的隐性兜底责任。
- **初始态度**：愿意合作，希望书记尊重政府分工。
- **掌握信息**：知道其中一家企业可能在两个月内出现流动性危机。

### 5.2 唐敏，市委秘书长

- **权限**：议程协调、材料流转和督查联络。
- **公开立场**：建议书记先统一班子认识。
- **真实关切**：维护市委运转，避免新书记被不完整材料误导。
- **掌握信息**：县里上报的就业人数可能明显偏低，但没有确证。

### 5.3 罗志诚，常务副市长

- **权限**：协助市长负责发展改革、财政、国资等工作。
- **公开立场**：主张市属国企参与整合，以时间换空间。
- **真实关切**：希望主导一个能够形成个人成绩的重组方案。
- **隐藏风险**：他提出的国企参与方式可能被认定为新的政府兜底。

### 5.4 邵文远，分管工业副市长

- **权限**：协调工信、能源和企业服务。
- **公开立场**：强调产业不能垮，主张延长整改周期。
- **真实关切**：过去两年一直为企业争取时间，担心此前判断被追责。
- **掌握信息**：企业曾口头承诺自行融资，但从未落实。

### 5.5 贺兰，市纪委书记、市监委主任

- **权限**：监督、调查和提出问责建议。
- **公开立场**：要求程序和资金安排经得住检查。
- **真实关切**：不反对改革性措施，但不能接受伪造数据或口头兜底。
- **掌握信息**：已经收到一封关于县企关系的匿名反映，内容尚未核实。

### 5.6 高维民，北山县委书记

- **权限**：领导北山县工作，能够影响基层执行和稳定处置。
- **公开立场**：完全服从市委决定，但强调就业安置必须由市里支持。
- **真实关切**：县财政和个人年度评价都不能承受企业集中停产。
- **掌握信息**：真实受影响就业人数高于正式上报，县里还欠企业部分补贴。

### 5.7 许仲平，市生态环境局局长

- **权限**：提出整改标准、监测和执法建议。
- **公开立场**：必须按省里要求完成可核验的阶段目标。
- **真实关切**：过去曾被要求“帮助企业过关”，现在不愿承担数据责任。
- **掌握信息**：一家企业已经开始临时停用污染较高的生产环节，存在窗口期。

### 5.8 韩泽，北岭能源集团董事长

- **权限**：控制最大一家企业的投资、用工和生产安排。
- **公开立场**：企业愿意整改，但需要银行和政府共同支持。
- **真实关切**：保住企业控制权，避免被市属国企低价整合。
- **掌握信息**：集团部分可抵押资产已经用于其他融资，尚未向政府完整披露。

### 5.9 魏舒，省城商行岚州分行行长

- **权限**：可以建议授信，但最终需要省行审批。
- **公开立场**：只支持有真实现金流和足额担保的方案。
- **真实关切**：避免现有贷款成为不良资产。
- **掌握信息**：若政府不提出可信方案，银行可能先行压缩授信。

## 6. 隐藏世界事实

这些事实由模拟内核保存，并按调查、人物选择和事件发展逐步暴露：

1. 县里上报直接受影响就业 7,400 人，真实人数约 11,200 人。
2. 北岭能源集团的可自由抵押资产少于其对政府的陈述。
3. 前任主持的一次专题会口头同意“必要时由市属国企参与保障”，但正式纪要刻意使用模糊表述。
4. 常务副市长的重组方案在工业上可行，但融资设计存在明显合规风险。
5. 如果八周内形成可信的分期方案，省级复核组可能接受阶段性完成，而非要求全部生产线立即退出。
6. 如果企业在第四周前感到政府将强制接管，董事长会转移部分订单和技术团队。
7. 如果县委书记获得明确的就业替代支持，会配合提供真实名单；否则会继续低报失业影响。

## 7. 六回合结构

### 回合一：材料互相矛盾

**时间**：第 1 周。

玩家收到：

- 生态环境局的整改倒计时；
- 工信局的产业影响简报；
- 北山县的稳定风险报告；
- 市政府关于财政空间的简要说明。

四份材料在就业人数、企业自筹能力和可否延期方面互相矛盾。

玩家有四点注意力，可以：

- 精读某份材料；
- 约谈市长、县委书记、环保局长或企业董事长；
- 要求秘书长独立核查就业数据；
- 直接下达初步指令。

**回合目标**：玩家形成第一份领导指令。

预设方向：

1. “整改期限不能突破，由市长牵头提出分期方案，严禁新增隐性债务。”
2. “先稳住就业和生产，由分管副市长向省里争取延期。”
3. “成立市委督办专班，由我亲自抓，先查清全部数据。”
4. “其他”：玩家自由输入。

系统不会要求玩家填写融资和技改清单，只解析目标、红线、授权和期限。

### 回合二：谁来起草方案

**时间**：第 2—3 周。

根据玩家授权，出现不同版本：

- 市长牵头：强调财政合规、分期退出和省级沟通；
- 常务副市长牵头：强调市属国企整合和快速形成项目；
- 工业副市长牵头：强调延期和企业自救；
- 书记亲自抓：各部门提交互不兼容的材料，信息更多但协调成本更高。

玩家审阅三类关键分歧：

- 是否承诺政府支持融资；
- 是否公开第一批关停名单；
- 是否先确认真实就业名单并制定安置底线。

**回合目标**：选定牵头机制，并决定要继续查什么。

### 回合三：条件交换

**时间**：第 4—5 周。

关键人物提出条件：

- 北山县要求市级提供就业项目和职业培训资金；
- 银行要求企业补充资产和政府给出明确的产业政策信号；
- 企业要求不被强制并入市属国企；
- 环保局要求任何分期都必须有可核验的停产和监测节点；
- 市长要求不以口头承诺形成财政兜底。

玩家可以进行两次约谈和一次协调会。形成的承诺会进入后续回合。

**回合目标**：获得足够支持，使方案具备执行基础。

### 回合四：常委会前后

**时间**：第 6 周。

玩家决定：

- 是否在会前个别沟通；
- 采用哪一版方案进入常委会；
- 哪些分歧写入会议材料；
- 是否向省里正式报告阶段性方案；
- 谁负责对外说明。

会议不是“票数小游戏”。班子支持影响责任共同体和后续执行；不同意见是否被如实保留，会影响未来风险。

**回合目标**：形成正式决策和责任链。

### 回合五：执行偏差

**时间**：第 7—9 周。

从以下事件中按状态触发一至两项：

- 银行因发现抵押不足暂停新增授信；
- 县里就业名单被举报严重低报；
- 企业开始转移订单；
- 环保局拒绝在数据不完整的报告上签字；
- 常务副市长要求追加国企过桥资金；
- 工人因欠薪在厂区聚集。

玩家可以：

- 坚持原方案并督办；
- 调整授权对象；
- 公开或内部纠正数据；
- 请求省级协调；
- 改变第一批关停范围；
- 提出自由文本应对。

**回合目标**：处理坏消息，同时决定是否承认此前判断存在问题。

### 回合六：复核与余波

**时间**：第 10—12 周。

省级复核组到达。结算考虑：

- 阶段性整改是否真实可核验；
- 就业安置是否有执行而非只有文件；
- 是否形成新增财政兜底；
- 玩家是否获得真实信息并及时纠偏；
- 班子是否共同执行；
- 哪些承诺尚未兑现；
- 是否留下审计、举报或人事风险。

短局结局不是简单胜败，而是生成一份十二周工作评价和未来六个月风险预告。

## 8. 主要策略路线

### 8.1 合规分期路线

由市长牵头，先核实数据、关停最高风险生产线、争取省级接受阶段计划，同时拒绝隐性财政兜底。

- **优势**：合规性高、责任链较清楚。
- **代价**：推进慢，需要与县里和企业反复谈判；可能出现短期失业。
- **关键条件**：真实数据、可信节点和省级沟通。

### 8.2 产业整合路线

由常务副市长推动市属国企整合企业和技改资产。

- **优势**：容易快速形成完整项目和统一口径。
- **代价**：财政和隐性债务风险高，企业可能抵制。
- **关键条件**：必须找到真实商业资金来源并限制政府责任。

### 8.3 企业自救路线

给企业更多自主空间和时间，以订单、资产和银行融资完成整改。

- **优势**：直接财政成本低，减少政府越位。
- **代价**：企业信息不透明，可能拖延或转移资产。
- **关键条件**：高质量监督、资产核查和明确退出节点。

### 8.4 强力督办路线

书记亲自盯数据、协调银行、县和企业。

- **优势**：短期优先级和信息获取显著提高。
- **代价**：消耗注意力，市长和分管领导责任弱化；所有问题更集中于玩家。
- **关键条件**：及时把临时督办恢复为可持续的责任链。

路线可以组合，但不存在同时获得全部优点的完美方案。

## 9. 自由文本示例

玩家输入：

> 省里期限不能硬顶，也不能用市属国企替企业兜债。请市长牵头，先把真实就业和企业资产查清，环保局提出分两批停产的最低合规方案。十天后给常委会三个选项。县里如果配合报真实名单，市里优先安排培训和新项目，但不承诺保住所有岗位。

系统应解析为：

- 目标：按期形成可核验的分期整改；
- 优先级：合规、真实数据、就业缓冲；
- 红线：不与省里正面对抗、不以国企承担企业债务；
- 授权：市长牵头；
- 调查任务：就业名单、企业资产；
- 方案要求：环保局提供两批停产底线，提交三个方案；
- 期限：十天；
- 条件性承诺：县里真实上报则优先获得培训和新项目支持；
- 明确未承诺：不保证全部岗位。

系统不应自行决定培训预算、具体停产设备或项目落在哪个园区。这些内容由市长及相关部门在下一回合方案中提出。

## 10. 一个可能的手工试玩轨迹

这一轨迹用于评审节奏，不代表最佳答案。

1. 玩家在回合一约谈市长，并要求秘书长核查就业数据。
2. 市长透露企业流动性风险；核查尚未完成，只确认县里口径可疑。
3. 玩家选择市长牵头，规定不得新增隐性债务，要求两周内提出三案。
4. 市长提交分期方案；常务副市长另推国企整合；县委书记拒绝承认失业规模。
5. 玩家向县委书记承诺：真实上报后优先安排培训和一个零部件项目，但不兜底企业债务。
6. 县里提交更完整名单，社会风险评估上升，方案因而需要提高安置支出。
7. 常委会通过分期方案，并如实记录常务副市长对资金来源的保留意见。
8. 第八周银行暂停授信。玩家选择公开承认融资条件变化，并请求省级协调银行对合规技改项目重新评估。
9. 复核时第一批生产线真实停产，就业冲击高于最初材料，但没有新增隐性债务。
10. 结局评价：整改阶段过关、组织信用上升、财政风险受控；北山县对就业支持的承诺仍未完全兑现，未来六个月存在信访和关系反噬风险。

## 11. 网页原型范围

### 11.1 必须有

- 开局介绍和姓名输入；
- DeepSeek API Key 门禁，默认 `deepseek-v4-flash`，并提供“记住 Key”和模板调试模式；
- 一页式主游戏界面；
- 四类材料阅读；
- 至少六名关键人物的约谈；每名人物只能使用其局部认知，模板模式也可完成；
- 每回合三个会谈时段，支持询问、试探、私下交办和条件交换；
- 私下谈话与正式决定的效力、知情范围和责任痕迹有明确区别；
- 预设选项和“其他”自由文本；
- 领导指令解析摘要；
- 两至三份由授权对象形成的方案；
- 一次常委会决策；
- 一次执行偏差；
- 最终十二周评价和未来风险；
- 本地存档和重新开始；
- 固定随机种子调试模式。

### 11.2 暂不做

- 完整城市地图；
- 自由行走或 3D 场景；
- 完整职业晋升；
- 复杂经济模型；
- 真实新闻抓取；
- 语音；
- 多人游戏；
- 每名 NPC 的无限、无成本自由聊天。

## 12. 成功标准

内部试玩至少满足：

1. 80% 以上玩家能说清书记决定了什么、哪些细节是下属决定的；
2. 玩家能够发现至少一处材料矛盾；
3. 至少两条策略路线被玩家认为合理；
4. 不同授权对象会产生可观察的方案差异；
5. 玩家作出的一项条件承诺在后续回合被主动提及；
6. 自由文本不能凭空创造财政、上级批准或全员支持；
7. 坏结果能够通过结算说明追溯到信息、权限、资源、关系或随机冲击；
8. 一局完成时间控制在 30—45 分钟；
9. 同一随机种子和同一结构化指令能够复现状态结果；
10. 没有 LLM 时，使用模板输出仍可完成整局测试。

## 13. 实现顺序建议

1. 先实现无 LLM 的结构化命令、状态和六回合固定内容；
2. 接入预设选项并完成确定性回放；
3. 接入自由文本指令解析；
4. 接入市长方案起草和少量 NPC 反应；
5. 最后接入叙事生成和界面流式输出；
6. 完成一轮人工平衡后，再考虑第二条事件链。

这样能够先验证它是不是一个游戏，再验证 LLM 是否让它更像一个活的政治世界。
