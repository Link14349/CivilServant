# CivilServant（暂名）

一款以中国地方治理为题材的、由 LLM 辅助驱动的单人政治治理模拟游戏。玩家扮演虚构地区的领导干部，在有限权力、有限信息、有限财政和多重责任约束下作出判断，经历调任、考核、晋升、平调、退居二线等职业变化，直至退休。

项目当前处于**设计阶段**，尚未编写运行时代码。

## 产品判断

本项目不是“官场题材选项小说”，也不是让多个 Agent 无约束聊天。核心产品形态是：

> 确定性模拟内核负责事实、资源、权限与后果；LLM 负责理解玩家意图、生成有立场的人物行为、起草材料并呈现叙事。

玩家扮演的是领导者，而不是超级项目经理。玩家主要决定目标、优先级、红线、授权方式和重大分歧；市长、分管领导、区县和职能部门负责提出并执行具体方案。放权会带来信息和执行偏差，越级直接干预则会消耗注意力并破坏责任链。

## 已确定的设计原则

1. **权力有限**：有议程权和协调权，不等于拥有无限资源或完美执行力。
2. **授权本身就是玩法**：不同牵头人会塑造不同方案，也会选择性汇报信息。
3. **事实分层**：世界真实状态、NPC 认知、呈给玩家的材料彼此分离。
4. **承诺跨回合存在**：人情、政策交换、会议记录、财政责任和审计痕迹不能在事件结束后消失。
5. **没有单一正确指标**：发展、财政、环境、民生、组织信用和行政能力相互制约。
6. **LLM 不裁定胜负**：模型可以解释和提议，最终状态变化由规则、数据和可复现随机数决定。
7. **完全虚构**：首个版本不使用真实人物、真实城市或未公开个人信息。

## 第一阶段目标

先完成一个可重复游玩的纵向切片，而不是直接制作完整仕途：

- 玩家担任虚构地级市市委书记；
- 围绕一条产业环保整改事件链进行六个回合；
- 能够阅示材料、约谈、定目标、授权、审议方案和处理执行偏差；
- 每个事件提供预设选项和“其他”自由输入；
- NPC 会依据权限、利益、认知和历史承诺作出反应；
- 同一初始状态和随机种子能够复现相同的结构化结果。

完成这一切后，再扩展至完整五年任期、跨岗位调任和退休结算。

## 暂不包含

- 真实城市和现实在任官员模拟；
- 大规模宏观经济仿真；
- 数十个常驻 LLM Agent 同时自主运行；
- 多人在线、交易系统或移动端原生应用；
- 由 LLM 任意修改世界状态或绕过制度规则。
